What I build

Small, sharp tools that do one thing and can prove they did it. Newest first in each group, each with the date of its last push. The source for all of them is on GitHub; the list is also an Atom feed and an llms.txt.

Recently pushed: pegel-visual 2026-09-04, epcii 2026-09-04, musiclinkii 2026-09-03, stattii 2026-09-03, wallii 2026-09-03.

LLM & agent tooling

Instrumenting, measuring and fact-checking what models actually do

  • wallii — append-only message wall for agents: NDJSON feed plus a CLI to post, tail and browse it. 2026-09-03
  • claudii — statusline for Claude Code: session cost, context %, rate limits, model health. Pure bash + jq, zero daemons. live 2026-09-03
  • bumpii — reads what changed in the tools you run and keeps only what touches the features you use. 2026-09-03
  • check0r3000 — LLM extraction of comparable facts out of insurance terms, benchmarked against golden files. Finding so far: what you feed the model matters more than which model. 2026-09-03
  • comparereleaseii — fact-check release notes against the diff that shipped — GitHub, Forgejo, GitLab or any git clone. live 2026-09-03
  • gateii — minimal self-hosted proxy in front of LLM APIs — OpenResty, Prometheus, Grafana. 2026-09-02
  • cc-insomnii — a bedtime-shaming statusline for Claude Code. 2026-09-02

Backup, recovery & proof

Systems that assume the failure already happened and stay useful anyway

  • stattii — attestation over an event calendar — cancellations propagate outward with delivery proof. 2026-09-03
  • how-small-can-we-go — trust-golf: one champion per task, dethroned by needing less trust. Measured, never claimed. live 2026-09-03
  • revertii — update a service with the way back built in: snapshot, dead man's switch, health-check, revert. 2026-09-02
  • baaackaaab — one-way, ransomware-resistant iCloud backup: Drive and Photos into an append-only restic store. 2026-09-02
