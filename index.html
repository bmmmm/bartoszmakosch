What I build

Small, sharp tools that do one thing and can prove they did it. Newest first in each group. The source for all of them is on GitHub; this list and llms.txt are generated from the same file, so they cannot say different things.

LLM & agent tooling

Instrumenting, measuring and fact-checking what models actually do

  • wallii — append-only message wall for agents: NDJSON feed plus a CLI to post, tail and browse it.
  • claudii — statusline for Claude Code: session cost, context %, rate limits, model health. Pure bash + jq, zero daemons. live
  • check0r3000 — LLM extraction of comparable facts out of insurance terms, with a model benchmark built into the tool.
  • bumpii — read what actually changed in the tools you run, judged against how you actually use them.
  • gateii — minimal self-hosted proxy in front of LLM APIs — OpenResty, Prometheus, Grafana.
  • comparereleaseii — fact-check release notes against the actual code diff — GitHub, Forgejo, GitLab or any git clone. live
  • cc-insomnii — a bedtime-shaming statusline for Claude Code.

Backup, recovery & proof

Systems that assume the failure already happened and stay useful anyway

  • stattii — attestation over an event calendar — cancellations propagate outward with delivery proof.
  • how-small-can-we-go — trust-golf: one champion per task, dethroned by needing less trust. Measured, never claimed. live
  • baaackaaab — one-way, ransomware-resistant iCloud backup: Drive and Photos into an append-only restic store.
  • revertii — update a service with the way back built in: snapshot, dead man's switch, health-check, revert.

Local-first web apps

Static pages that keep your data in your own browser

  • putzii — cleaning schedule shared by capability link, with QR check-in. No backend at all. live
  • gymii — floor-plan your gym, log sets against numbered machines. Offline-first, data never leaves the device. live
  • kuvertii — read what an email header says about you — who it was really addressed to, where the unsubscribe link leads. live
  • musiclinkii — turn one music link into links for every streaming platform. live
  • shieldchipiii — stone-chip logbook for your windshield, so the insurance conversation has a record instead of a memory. live
  • app-icons-generator — every iOS, macOS and watchOS icon size from one 1024px PNG — CLI and browser. live
  • db-wallet — drink tracking wallet for the crowd at bitcircus101.de and Datenburg e.V. Bonn. live

Terminal & macOS

Things that live in a shell, or in the menu bar next to it

  • pegel-visual — live ASCII water levels for German rivers, with an optional aircraft overlay from your own ADS-B receiver. live
  • youtubehistii — local YouTube watch-history analyzer — topics, and consume vs. learn. Fully on-device.
  • epcii — EPC QR code (GiroCode) generator — one static binary with its own QR encoder core.
  • pwdtintii — the terminal background takes its colour from the directory you are in. zsh, bash, fish, tmux-aware.
  • vpnii — VPN status in the zsh prompt, on top of WireGuard and Tailscale.
  • audioctl — switch macOS output and input devices, volume, mute and sample rate from the CLI.
  • KeebLock — locks the keyboard while you clean it, with animations worth the thirty seconds.
  • git-times-live — a standalone live broadcast TV channel for your git activity. live

FreshRSS extensions

Four small extensions for the reader I actually use every day

  • NoteDrop — drop notes and links on one device, copy them on another with one click.
  • ClickHistory — keeps a history of the article links you actually opened.
  • ShareViaQRCode — a large QR code for the current article, so a phone can pick the link off the screen.
  • ExitReaderView — a floating button to leave the reading view in one click.
